SmartEasyBIM CDE

Ambiente Comum de Dados (ISO 19650) servido por este computador para a rede do escritório.

Iniciando…

Os colegas acessam pelo navegador (e o SmartEasyBIM se conecta) em:

    Use o endereço com o nome do computador ou o número (IP). "localhost" só funciona neste computador.

    Dados

    Banco (cde.sqlite), arquivos enviados (pasta "arquivos") e cópias diárias do banco ("backups"). Faça backup desta pasta.

    Ao trocar de pasta, o CDE passa a usar a nova (vazia, ou uma pasta de dados copiada de outro servidor).

    SmartEasyWEB

    Ligado, o servidor guarda os arquivos dos empreendimentos do SmartEasyWEB e só aceita operações autorizadas por ele (assinatura conferida com a chave pública buscada agora).

    Configuração

    Fechar esta janela não desliga o CDE: ele continua na bandeja do sistema. Para desligar, use "Sair" no ícone da bandeja. Na primeira vez, permita o acesso à rede quando o Firewall do Windows perguntar.
